# Deprecation of {{site.data.keyword.cos_full}} SDK V1
{: #deprecation-cos-sdk-v1}

{{site.data.keyword.cloud_notm}} continues to evaluate its service offerings periodically, keeping in perspective client requirements and market direction. As a result, {{site.data.keyword.cos_full}} SDK v1 reaches end of support on 06 August 2027.
{: shortdesc}

## Important dates
{: #deprecation-cos-sdk-v1-dates}

| Stage | Date | Description |
|---------------------------|----------------------|----------------------------------------------------|
| End of support | 06 August 2027 | {{site.data.keyword.cos_short}} SDK v1 no longer receives updates, security fixes, or new releases after this date. |
{: caption="Important dates" caption-side="top"}

## Deprecation details
{: #deprecation-cos-sdk-v1-details}

-	Support for {{site.data.keyword.cos_short}} SDK v1 ends on 06 August 2027.
-	After this date, SDK v1 no longer receives updates, security fixes, or new releases.
-	IBM recommends migrating to {{site.data.keyword.cos_full_notm}} SDK v2, which provides improved performance, enhanced security, modern APIs, and continued support.

## Next steps for current users
{: #deprecation-cos-sdk-v1-next-steps}

Plan your migration to a supported SDK version before 06 August 2027: migrate from SDK Node.js v1 to [{{site.data.keyword.cos_full_notm}} SDK Node.js v2](/docs/cloud-object-storage?topic=cloud-object-storage-node-v2), from SDK Go v1 to [{{site.data.keyword.cos_full_notm}} SDK Go v2](/docs/cloud-object-storage?topic=cloud-object-storage-go-v2), and from SDK Java v1 to [{{site.data.keyword.cos_full_notm}} SDK Java v2](/docs/cloud-object-storage?topic=cloud-object-storage-java-v2).
